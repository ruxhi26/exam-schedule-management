EXAM SCHEDULE MANAGEMENT SYSTEM - XAMPP SETUP

1. Copy the folder 'exam_schedule' into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Import database.sql.
5. Open http://localhost/exam_schedule/setup_admin.php once.
6. Delete setup_admin.php after it runs.
7. Open http://localhost/exam_schedule/
8. Admin login: admin / admin123
9. Student demo roll no: 22

MODULES:
- Admin Login / Logout
- Admin Dashboard
- Subject CRUD
- Room Management
- Exam Schedule Management
- Student Login
- Student Search / View

TECHNOLOGY:
HTML, CSS, PHP, MySQL, XAMPP
